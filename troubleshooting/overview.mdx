## Luke does not respond

First confirm that The Direction Company has explicitly enabled Luke for the organization and provider. No channel is publicly listed as generally available yet.

## Luke cannot see a source

Ask Luke to explain which organization, workspace, identity, connection, and permission boundary it resolved. Do not paste restricted source content into a broader conversation as a workaround.

## Luke has the wrong context

State the correction, name the authoritative source when known, and ask Luke to show how the recommendation changes.

> That context is outdated. Use the approved decision from the release thread and explain what changed.

## A provider action was denied or expired

Return to the originating conversation. Luke should recheck current provider state rather than treating a click or redirect as success.

## The feature is unavailable

Treat the message as the current state. A planned or internally evaluated capability is not available merely because it appears in a roadmap or an earlier example.
